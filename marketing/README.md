## How to Use the SVG Files

SVG files are scalable vector graphics — open them in any browser to preview at full quality.

**To export as PNG/JPG for posting:**
1. Open the SVG in Chrome/Safari
2. Right-click → "Save image as" (Chrome) or use a screenshot tool
3. Or open in Figma/Illustrator for professional export

**Recommended export sizes:**
- Instagram Posts: 1080×1080 px (already sized correctly)
- Instagram Stories: 1080×1920 px (already sized correctly)
